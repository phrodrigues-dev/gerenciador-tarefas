# Gerenciador de Tarefas

É um pequeno gerenciador que lista as tarefas adicionadas pelo usuário e marcar tarefas como concluídas.

## Funcionalidades

- Listar: Lista todas as tarefas adicionadas pelo usuário.
- Adicionar: Permite adicionar uma tarefa.
- Concluir: Marca a tarefa escolhida como concluída.
- Remover: Remove a tarefa digitando seu número.

## Como executar

Para utilizar basta ter o Python instalado e rodar:
```
python main.py
```

## Tecnologia utilizada

Python.
